1. 程序是做什么的
--------------------------------------------------------------------------------

relay-c 是本机运行的继电器 / 板级控制服务：

  - 通过串口控制继电器模块（支持 A0 标准协议与自定义 hex/str 命令）
  - 把「复位 / 镜像升级 / 自定义动作」封装成板级语义
  - 提供 Web 控制页与 HTTP API（均为 GET），便于人工操作或脚本/AI 调用

典型用途：实验室多板复位、烧录进升级模式、风扇/电源等自定义开关。

2. 解压后目录里有什么
--------------------------------------------------------------------------------

  relay-c.exe              主程序（必须与同目录 DLL 一起保留）
  *.dll                    运行时依赖（勿删、勿挪走）
  run.bat                  一键启动（推荐）
  boards.json.example      配置模板
  README.txt               快速入门
  使用说明.txt             本文档（详细说明）
  VERSION.txt              本构建的版本号、编译时间、过期时间

首次使用请生成 boards.json（见下一节）。

--------------------------------------------------------------------------------
3. 快速开始（最短路径）
--------------------------------------------------------------------------------

  1) 解压 zip 到任意目录（建议英文路径）
  2) 复制并编辑配置：
       copy boards.json.example boards.json
     修改：
       - relays.*.windows_port（如 COM18）
       - boards.* 绑定的 relay / channel
       - server.port（默认 18053）
  3) 双击 run.bat，或命令行：
       relay-c.exe -c boards.json
  4) 浏览器打开：
       http://127.0.0.1:18053/

无硬件时可先用模拟模式验证界面与 API：

       relay-c.exe -c boards.json -n

--------------------------------------------------------------------------------
4. 配置要点（boards.json）
--------------------------------------------------------------------------------

顶层：

  server.port     HTTP 端口（默认 18053）
  relays          继电器模块定义
  boards          板级行为定义

继电器 relays 常用字段：

  enabled / windows_port / linux_port / relay_channels / baudrate
  io_inverted     接线取反时置 true
  channels        可选；按通道自定义 on/off hex 或 str 命令
  startup_init    "on" | "off" | 省略(不操作)

板级 boards 常用字段：

  reset           复位脉冲（hold_seconds、polarity_inverted）
  upgrade_mode    镜像升级模式（存在且 enabled=true 才可用）
  actions         自定义标签动作（pulse / hold_on / hold_off）

约束：同一 relay 上 reset 与 upgrade_mode 不能使用相同通道。

--------------------------------------------------------------------------------
5. Web 与 HTTP API（摘要）
--------------------------------------------------------------------------------

页面：

  /         控制页
  /config   配置编辑（可热重载）
  /docs     API 文档
  /api/health

常用 API 示例：

  curl "http://127.0.0.1:18053/api/boards/demo_board/action?action=reset"
  curl "http://127.0.0.1:18053/api/boards/demo_board/action?action=upgrade"
  curl "http://127.0.0.1:18053/api/relays/com18_test/relay?channel=1&state=true"
  curl "http://127.0.0.1:18053/api/serial/ports"
  curl "http://127.0.0.1:18053/api/config/reload"

完整接口说明见网页 /docs。

8. 常见问题
--------------------------------------------------------------------------------

Q: 双击无反应 / 闪退？
A: 在命令行运行 relay-c.exe version / relay-c.exe -c boards.json 查看报错；
   确认 DLL 与 exe 在同一目录；确认端口未被占用。

Q: 串口打不开？
A: 检查 boards.json 中 windows_port；设备管理器确认 COM 号；
   关闭占用该串口的其他程序；或先用 -n 验证软件本身。

Q: 继电器动作相反？
A: 将对应 relay 的 io_inverted 设为 true；板级还可调 polarity_inverted。

Q: 包里有源码吗？
A: 没有。本发行包仅含可执行文件与运行依赖。
